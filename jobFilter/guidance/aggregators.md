# Listings that are not the employer's form
- **startup.jobs** (`startup.jobs/<slug>-<id>`): this is an aggregator page. Click its **Apply** button; it opens the company's own application (Greenhouse, Lever, Ashby, ...). Continue there and follow that system's notes. Report the company page URL as `page_url`.
- **Simplify** links point straight at the employer's form; some carry `utm_source=Simplify` in the URL, which is harmless.
