# Workday (`*.myworkdayjobs.com`)
- Requires an account per company (wizard step 1, "Create Account/Sign In"). Use the core login handoff: fill the email, stop with `needs_login`, and continue after the user has created the account with Chrome's strong password. Workday's password rules (8+ chars, upper, lower, digit, special) are met by Chrome's suggestion. A verification email may follow; that is part of the user's step.
- The Apply button opens a "Start Your Application" dialog (Autofill with Resume / Apply Manually / Use My Last Application, sometimes Apply With LinkedIn). Cookie banners shift the layout by ~100 px; re-screenshot after dismissing one.
- Start choice: prefer **Autofill with Resume** to get the skeleton, but treat everything it produces as a draft to verify field by field (it picks wrong schools, drops company names, turns projects into jobs and leaves Degree at "Select One").
- Dropdowns (`button[aria-haspopup]`) can be driven by JS: click the button, wait ~1 s, click the `[role=option]` with matching text; press Escape before opening the next one and read the button text back to confirm. Textareas, checkboxes and "Save and Continue" need real clicks (`computer` left_click), not JS clicks.
- Wizard steps: **My Information** → **My Experience** → **Application Questions** → **Voluntary Disclosures** → **Self Identify** → **Review**. Click "Save and Continue" between steps; validation errors appear at the top of the step and as red text under fields.
- Fields carry `data-automation-id` attributes (e.g. `legalNameSection_firstName`, `addressSection_addressLine1`, `phone-number`); use them in `find`/JS. Country, phone device type, state and "How did you hear" are custom dropdowns: click the button, then click the option text.
- **My Information**: Legal Name first/last; tick the **"I have a preferred name"** checkbox and fill Preferred Name from `profile.identity.preferred_name` when it is set. Address (line 1, line 2 if set, city, state, postal code), email is fixed to the account, phone device type + number.
- **My Experience**: one Work Experience block per job (Job Title, Company, Location, "I currently work here", From/To month-year, Role Description). The Role Description textarea gets that job's bullets from ROLE DESCRIPTIONS as described in the workflow; the autofill version is wrong (wrapped lines, missing first bullet). Education blocks: school, degree, field of study, GPA, dates. Websites: add LinkedIn and GitHub. Confirm the resume file is attached in the Resume/CV section.
- **Application Questions** are company-specific; answer from profile/bank, ask only when nothing fits.
- **Voluntary Disclosures / Self Identify**: EEO from `profile.eeo`; "decline" → "I do not wish to answer". Leave binding terms for the user, as required by the core workflow.
- On the Review step stop; the button there is Submit. Screenshot it.
